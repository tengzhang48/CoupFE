# Volumetric locking of generated axisymmetric elements

This example compares axisymmetric elements generated by `coupfe.codegen` on a
problem with an independent reference: a thick neo-Hookean spherical shell
inflated by internal pressure.

The elements are Python declarations (`kernels.py`): a Yeoh material
(`W = C10 (I1b-3) + C20 (I1b-3)^2 + C30 (I1b-3)^3 + K/2 (J-1)^2`) with a
displacement weak form and a mixed u–p weak form. Each element/formulation
pair is generated for the native CoupFE ABI with an `*_axi` element
configuration, compiled once with f2py (cached by source hash; set
`COUPFE_AXI_KERNEL_CACHE` to choose the directory) and run through
`coupfe.ElementGroup`.

The shell spans `A = 1 <= rho <= B = 2` with shear modulus `G = 1` and is
inflated to `p = 0.6 G`. Its meridian quarter (`r >= 0`, `z >= 0`) is meshed
with 6 radial by 8 angular cells; triangles split each cell in two. The inner
surface carries a prescribed cavity pressure through
`coupfe.AxisymmetricCavity`, `z = 0` is a symmetry plane and `r = 0` the
axis. Two bulk moduli are used:

- `K/G = 100` (`nu = 0.495`) is compared with a spherically symmetric
  boundary-value solve of the same law (`scipy.integrate.solve_bvp`, with
  independently written principal-stretch stresses; no finite elements).
- `K/G = 10 000` (`nu = 0.49995`) is compared with the closed-form
  incompressible neo-Hookean relation
  `p = G [2/lb + 1/(2 lb^4) - 2/la - 1/(2 la^4)]`, `la = a/A`, `lb = b/B`,
  `b^3 = B^3 + a^3 - A^3`, whose compressibility correction is `O(G/K)`.

The reported error is in the inner-surface displacement `a - A`.

```bash
PYTHONPATH=. python examples/axisymmetric_locking/run.py
```

## Reading the table

- **Linear displacement elements lock well before the incompressible limit.**
  Fully integrated Quad4 and Tri3 are already about 35% too stiff at
  `nu = 0.495` and almost rigid at `nu = 0.49995`.
- **F-bar removes the Quad4 locking.** Its remaining error of about 1% is
  ordinary discretization error on this coarse mesh and decreases under
  refinement (`tests/test_axisymmetric.py`).
- **Quadratic elements are much less sensitive.** Standard Quad8 and Tri6 are
  accurate at `nu = 0.495`; at `nu = 0.49995` standard Tri6 drifts and fully
  integrated Quad8 no longer converges here, while 2x2 reduced integration
  and the mixed u–p pairs stay within 0.01%.

## Generated formulations

The `*_axi` configurations use coordinates `(r, z)`, the hoop stretch
`F_tt = 1 + u_r / r` in the full three-dimensional deformation gradient, and
the ring weight `2 pi r`, so residuals are total forces.

- `standard`: displacement element; full integration unless the `quad8r_axi`
  configuration (2x2) is chosen.
- `fbar` (Quad4): CoupFE's F-bar, `Fbar = (Jbar/J)^(1/3) F` including the hoop
  stretch, with `Jbar` the ring-weighted element average of `J` and the
  residual `int P(Fbar) : delta F dV`. The tangent is unsymmetric.
- `mixed`: continuous corner pressure (Quad8/Quad4, Tri6/Tri3), from
  `int [W_iso + p (J - 1) - p^2/(2K)] dV`; mid-side pressure slots are
  prescribed by the caller (`kernels.unused_pressure_dofs`).

Scope: this is an element-verification study for one smooth, pressure-loaded
problem. It does not establish inf-sup stability, inversion robustness or
contact accuracy; see `tests/test_axisymmetric.py` for the patch, tangent,
contact, cavity and broken-control checks.
